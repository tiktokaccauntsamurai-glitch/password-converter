# Папка экспорта

Сюда пишутся результаты:

| Файл | Что это |
|---|---|
| `apple_passwords.csv` | импорт в Apple Passwords (без потерь) |
| `chrome_passwords.csv` | импорт в Chrome / Google Password Manager (без TOTP) |
| `firefox_logins.csv` | импорт в Firefox (только url / логин / пароль) |
| `pwvault_full_backup.csv` | полный бэкап со всеми полями и категориями |
| `print_a4.html`, `print_a6.html`, `print_notebook.html` | листы для печати |
| `print_*.pdf` | те же листы с точным размером страницы |
| `pwvault_audit.log` | журнал действий — паролей в нём нет по построению |

Эта папка **не должна** находиться внутри папки импорта: шреддер уничтожил бы
собственный результат. Программа это проверяет и предупреждает.

CSV здесь — плейнтекст. Импортируйте их в целевой менеджер паролей и удаляйте.
